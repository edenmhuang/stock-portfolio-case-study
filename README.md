# Stock Portfolio Prediction Case Study

An end-to-end machine learning pipeline in **R** that predicts 12-month stock returns from company financial fundamentals and builds an optimized **$1,000,000**, 12-stock portfolio.

**Result:** +25.3% return · **$252,658 profit** · 7th of ~50 analysts

---

### What's here

This repo is a **case-study write-up**, not a code drop. It presents the problem, methodology, and results, with illustrative snippets. The full graded solution (notebooks + data) is intentionally **not published** to respect course academic-integrity policy.

---

### Publish it on GitHub Pages (free, ~3 minutes)

1. Create a new repo on GitHub (public if you want it visible as a portfolio piece).
2. Upload the **contents of this `case-study-site/` folder** to the repo root, so `index.html` sits at the top level. (Drag-and-drop works: repo → *Add file* → *Upload files*.)
3. Go to **Settings → Pages**.
4. Under *Build and deployment* → *Source*, choose **Deploy from a branch**.
5. Set branch to **`main`** and folder to **`/ (root)`**, then **Save**.
6. Wait ~1 minute. Your site goes live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
7. Update the two `YOUR-USERNAME/YOUR-REPO` links above once you know the URL.

> Prefer to keep the repo root clean? Put these files in a `/docs` folder instead and pick **`/docs`** as the Pages source in step 5.
